If a video **buffers a lot**, **stops around the 1:00 mark**, or some **quality options are missing**, work through the fixes below in order. These steps apply to both **YouTube** and **YouTube Music**.

## First — update the apps

Download the latest **YouTube** / **YouTube Music** builds from the [Apps page](/Apps/) and install them over the old versions. Older apps often break when Google changes how playback works.

## Fix 1 — Change the playback mode (easiest)

This usually fixes the problem and does **not** need PotHelper.

1. Open **YouTube** (or **YouTube Music**)
2. Go to **Settings → Morphe → Miscellaneous → Spoof video streams → Default client**
3. Pick a different option, then play a video again

For **YouTube Music**, these options often work well:

- **Android Music Reel**
- **TV**
- **Android Music No SDK**

### Extra checks

| What to try | How |
| --- | --- |
| Background play | Under Morphe → Miscellaneous, try turning **Disable background playback restrictions** **off** |
| Network | Try a different Wi‑Fi network, or a VPN in another country |
| Account | Sign in with a different Google account |

## Fix 2 — Install PotHelper

Use this when Fix 1 does not help. You install a small helper app, then turn on **PoToken provider** in settings. This does **not** work for every account or region.

:::warning[Important]
If PotHelper does not help, go back to Fix 1 and try another playback mode.
:::

### 1. Install PotHelper

1. Download **PotHelper** from the [Apps page](/Apps/)
2. Install the app file (allow unknown apps if Android asks)
3. Leave PotHelper installed — YouTube uses it in the background

### 2. Turn it on in YouTube

1. Open **YouTube** (or **YouTube Music**)
2. Go to **Settings → Morphe → Miscellaneous → Spoof video streams** and set it to **Disabled**
3. Go to **Settings → Morphe → Miscellaneous → PoToken provider** and turn it **On**
4. Restart the app when asked
5. Play a video and check that it continues past 1:00

## Still stuck?

1. Reinstall **MicroG**, then YouTube / YouTube Music, from the [Apps page](/Apps/)
2. Retry Fix 1 with a different playback mode
3. Retry Fix 2 with a fresh PotHelper install
4. Confirm you are on a recent build under **Settings → Morphe → About**

### Advanced

If you build the apps yourself with Morphe Manager:

1. Turn on **pre-release** for the Morphe patch source (lower-left switch in Manager)
2. Repatch YouTube / YouTube Music with the latest patches

Upstream discussion: [morphe-patches#327](https://github.com/MorpheApp/morphe-patches/issues/327).
