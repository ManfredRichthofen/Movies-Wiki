백그라운드 재생이 되는 광고 없는 음악 스트리밍 — Android 기기에 APK로 설치합니다.

**처음이신가요?** [설치 가이드](/ko/docs/youtube-apps/install-on-android/)를 따르세요. YouTube용으로 **MicroG**를 이미 설치했다면 [앱 페이지](/Apps/)에서 **YouTube Music**만 받으면 됩니다.

## 제공 기능

- 곡 사이 광고 없음
- 백그라운드 재생
- 화면 속 화면(PIP)
- 오프라인 청취(지원되는 경우)

## 추가 문제 해결

**재생이 버퍼링되거나, 1:00에서 멈추거나, 화질 옵션이 없음**

- [재생 문제 가이드](/ko/docs/youtube-apps/playback-issues/)를 따르세요 — 먼저 스푸프 클라이언트, 그다음 PotHelper / PoToken을 시도하세요.

**로그인할 수 없음**

- **MicroG**가 설치되어 있고 거기서 먼저 로그인했는지 확인하세요.

**앱이 업데이트되지 않음**

- [앱 페이지](/Apps/)에서 최신 **YouTube Music** APK를 받아 기존 버전 위에 설치하세요.

## 업데이트

재생이나 로그인이 안 되면 [앱 페이지](/Apps/)에서 새 빌드를 확인하세요.
