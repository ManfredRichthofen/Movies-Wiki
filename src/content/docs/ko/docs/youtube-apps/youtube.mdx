백그라운드 재생, SponsorBlock 등 프리미엄급 기능이 있는 광고 없는 YouTube — Android 기기에 APK로 설치합니다.

**처음이신가요?** [설치 가이드](/ko/docs/youtube-apps/install-on-android/)부터 시작하세요 — 다운로드, MicroG, 로그인을 단계별로 다룹니다.

## 제공 기능

- 영상 광고 없음
- 백그라운드 재생
- 화면 속 화면(PIP)
- SponsorBlock (스폰서 구간 건너뛰기)
- 커스텀 테마

## 추가 문제 해결

**재생이 버퍼링되거나, 1:00에서 멈추거나, 화질 옵션이 없음**

- [재생 문제 가이드](/ko/docs/youtube-apps/playback-issues/)를 따르세요 — 먼저 스푸프 클라이언트, 그다음 PotHelper / PoToken을 시도하세요.

**영상은 나오는데 소리가 없음**

- 앱 설정에서 **Direct play**를 끄거나 더 낮은 화질을 선택하세요.

**앱이 업데이트되지 않음**

- [앱 페이지](/Apps/)에서 최신 **YouTube** APK를 받아 기존 버전 위에 설치하세요. 실패하면 기존 앱을 먼저 제거한 뒤 새 APK를 설치하세요.

## 업데이트

[앱 페이지](/Apps/)에서 새 빌드를 주기적으로 확인하세요. Google 쪽 YouTube가 업데이트되면 새 빌드가 나오기 전까지 오래된 APK가 작동을 멈출 수 있습니다.
