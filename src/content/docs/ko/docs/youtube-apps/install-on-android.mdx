이 가이드는 Android 휴대폰이나 태블릿에 **광고 없는 YouTube**와 **YouTube Music**을 설치하는 과정을 안내합니다. 세 개의 파일을 다운로드하고 정해진 순서로 설치합니다.

:::info[필요한 것]
- **Android 휴대폰 또는 태블릿** (Android 8.0 이상)
- 약 **200 MB**의 여유 저장 공간
- 몇 분 — 컴퓨터는 필요 없음
:::

## 1단계 — 앱 다운로드

휴대폰에서 [앱 페이지](/Apps/)를 열고 다음 파일을 다운로드하세요:

1. **MicroG** — 필수 헬퍼 앱 (**먼저** 설치)
2. **YouTube** 및/또는 **YouTube Music** — 하나 또는 둘 다 선택

브라우저가 `.apk` 파일을 저장합니다. **다운로드** 폴더나 브라우저의 다운로드 목록에서 찾을 수 있습니다.

## 2단계 — 브라우저에서 설치 허용

Android는 Play Store 밖의 앱을 한 번 허용하기 전까지 차단합니다.

1. **설정**을 엽니다
2. **알 수 없는 앱 설치**를 검색합니다 (기기마다 문구가 다름)
3. **브라우저**(Chrome, Samsung Internet 등)를 탭합니다
4. **이 소스 허용**을 켭니다

APK를 받은 브라우저에 대해 한 번만 하면 됩니다.

## 3단계 — MicroG 설치

1. **다운로드** 폴더를 엽니다 (또는 브라우저에서 완료된 다운로드를 탭)
2. **MicroG** 파일을 탭합니다
3. **설치**를 탭합니다 — 요청되면 알 수 없는 앱을 허용
4. 끝나면 **열기**를 탭합니다
5. 요청하는 권한을 허용하고 **백그라운드에서 실행**을 허용합니다

:::warning[MicroG를 유지하세요]
나중에 MicroG를 제거하지 마세요. YouTube와 YouTube Music이 로그인하고 백그라운드 재생하려면 필요합니다.
:::

## 4단계 — YouTube 또는 YouTube Music 설치

1. **다운로드**로 돌아갑니다
2. **YouTube** 또는 **YouTube Music** 파일을 탭합니다
3. **설치**를 탭합니다

:::tip[이미 YouTube가 설치되어 있나요?]
Play Store의 일반 YouTube 앱을 먼저 제거하세요. 그렇지 않으면 새 앱 설치가 실패할 수 있습니다.
:::

## 5단계 — 로그인 및 테스트

1. **YouTube**(또는 **YouTube Music**)를 엽니다
2. **Google 계정**으로 로그인합니다
3. 동영상이나 노래를 재생하세요 — **광고가 없어야** 합니다
4. 휴대폰을 잠그세요 — 오디오가 **계속 재생**되어야 합니다

로그인에 실패하면 **MicroG**를 열고 거기서 로그인했는지 확인한 뒤, 휴대폰을 재시작하고 다시 시도하세요.

## 문제가 생겼나요?

| 증상 | 시도할 방법 |
| --- | --- |
| 설치가 차단됨 | 브라우저에 대해 “알 수 없는 앱 설치”를 켭니다 (2단계) |
| “앱이 설치되지 않음” | 기본 YouTube/YouTube Music을 제거하고, 저장 공간을 확보한 뒤 [/Apps](/Apps/)에서 APK를 새로 받으세요 |
| 로그인 루프 | MicroG를 재설치하고 MicroG에서 먼저 로그인한 뒤 YouTube를 여세요 |
| 백그라운드 오디오 없음 | 설정 → 배터리 → **MicroG**와 **YouTube**를 **제한 없음**으로 설정 |
| 앱 충돌 | [/Apps](/Apps/)에서 최신 APK를 받으세요 — YouTube가 업데이트되면 오래된 빌드는 작동을 멈춥니다 |
| 버퍼링 / 1:00에서 멈춤 / 화질 없음 | [YouTube 재생 문제 해결](/ko/docs/youtube-apps/playback-issues/)을 참고하세요 |

더 도움이 필요하신가요? [YouTube](/ko/docs/youtube-apps/youtube/)와 [YouTube Music](/ko/docs/youtube-apps/youtube-music/) 페이지의 추가 팁을 참고하세요.
