재생이 **버퍼링**되거나, **1:00 근처에서 멈추거나**, 일부 **화질이 없으면** 아래 두 가지 해결책을 순서대로 시도하세요. **YouTube**와 **YouTube Music** 모두에 적용됩니다.

:::tip[먼저 할 일]
[앱 페이지](/Apps/)에서 최신 **YouTube** / **YouTube Music** 빌드를 받으세요. Google이 재생 방식을 바꾸면 오래된 APK가 자주 깨집니다.
:::

## 해결책 1 — 비디오 스트림 스푸프

먼저 이걸 사용하세요. PotHelper가 필요 없습니다.

1. **YouTube**(또는 **YouTube Music**)를 엽니다
2. **설정 → Morphe → 기타 → Spoof video streams → Default client**로 이동합니다
3. 클라이언트를 바꾼 뒤 동영상을 다시 재생합니다

**YouTube Music**에서는 다음 클라이언트 중 하나를 시도하세요:

- **Android Music Reel**
- **TV**
- **Android Music No SDK**

### 추가 확인

| 설정 | 시도할 방법 |
| --- | --- |
| 백그라운드 재생 | 일부 사용자는 Morphe → 기타에서 **Disable background playback restrictions**를 **끔**으로 두어야 합니다 |
| 네트워크 | 다른 국가 VPN을 시도하세요 (여러 개 시도) |
| 계정 | 다른 YouTube / Google 계정으로 로그인하세요 |

## 해결책 2 — PotHelper로 PoToken

해결책 1로 재생이 안 될 때 사용하세요. PoToken은 추가 헬퍼 앱이 필요하며, **모든** 계정이나 지역에서 작동하지는 않습니다.

:::warning[중요]
PoToken은 모든 사용자에게 작동하지 않습니다. 해결책 1을 대체 수단으로 유지하세요.
:::

### 1. PotHelper 설치

1. [앱 페이지](/Apps/)에서 **PotHelper**를 다운로드합니다
2. APK를 설치합니다 (Android가 요청하면 알 수 없는 앱 허용)
3. PotHelper를 설치된 채로 두세요 — YouTube가 백그라운드에서 사용합니다

최신 릴리스는 [MorpheApp/PotHelper](https://github.com/MorpheApp/PotHelper/releases/latest)에 게시됩니다.

### 2. PoToken을 지원하는 빌드 사용

[앱 페이지](/Apps/)에서 PoToken provider 옵션이 포함된 최근 YouTube / YouTube Music APK인지 확인하세요.

Morphe Manager로 직접 패치하는 경우:

1. Manager 왼쪽 아래 스위치로 Morphe 패치 소스의 **pre-release**를 켭니다
2. 최신 패치로 YouTube / YouTube Music을 다시 패치합니다

### 3. 앱에서 PoToken 사용

1. **YouTube**(또는 **YouTube Music**)를 엽니다
2. **설정 → Morphe → 기타 → Spoof video streams**로 가서 **Disabled**로 설정합니다
3. **설정 → Morphe → 기타 → PoToken provider**로 가서 **On** / **Enable**로 켭니다
4. 안내가 나오면 앱을 다시 시작합니다
5. 동영상을 재생해 1:00 이후에도 되는지 확인합니다

## 여전히 막혔나요?

1. **설정 → Morphe → 정보**에서 패치 / 빌드 시점을 확인하세요
2. [앱 페이지](/Apps/)에서 **MicroG**, 그다음 YouTube / YouTube Music을 재설치하세요
3. 다른 스푸프 클라이언트로 해결책 1을 다시 시도하세요
4. PotHelper를 새로 설치한 뒤 해결책 2를 다시 시도하세요
