영상이 **자주 버퍼링**되거나, **1:00 근처에서 멈추거나**, 일부 **화질 옵션이 없다면** 아래 해결 방법을 순서대로 시도하세요. **YouTube**와 **YouTube Music** 모두에 해당합니다.

## 먼저 — 앱을 최신으로

[앱 페이지](/Apps/)에서 최신 **YouTube** / **YouTube Music**을 받아 기존 버전 위에 설치하세요. Google이 재생 방식을 바꾸면 오래된 앱이 자주 깨집니다.

## 해결 1 — 재생 모드 바꾸기 (가장 쉬움)

대부분 이 방법으로 해결되며 **PotHelper는 필요 없습니다**.

1. **YouTube**(또는 **YouTube Music**)을 엽니다
2. **설정 → Morphe → 기타 → Spoof video streams → Default client**로 이동합니다
3. 다른 옵션을 고른 뒤 영상을 다시 재생합니다

**YouTube Music**에서는 다음 옵션이 잘 맞는 경우가 많습니다:

- **Android Music Reel**
- **TV**
- **Android Music No SDK**

### 추가 확인

| 시도할 것 | 방법 |
| --- | --- |
| 백그라운드 재생 | Morphe → 기타에서 **Disable background playback restrictions**를 **끔**으로 시도 |
| 네트워크 | 다른 Wi‑Fi를 쓰거나, 다른 국가 VPN을 시도 |
| 계정 | 다른 Google 계정으로 로그인 |

## 해결 2 — PotHelper 설치

해결 1이 안 될 때 사용합니다. 작은 헬퍼 앱을 설치한 뒤 설정에서 **PoToken provider**를 켭니다. 모든 계정·지역에서 되지는 않습니다.

:::warning[중요]
PotHelper로도 안 되면 해결 1로 돌아가 다른 재생 모드를 시도하세요.
:::

### 1. PotHelper 설치

1. [앱 페이지](/Apps/)에서 **PotHelper**를 다운로드합니다
2. 앱 파일을 설치합니다 (Android가 물으면 알 수 없는 앱 허용)
3. PotHelper는 그대로 두세요 — YouTube가 백그라운드에서 사용합니다

### 2. YouTube에서 켜기

1. **YouTube**(또는 **YouTube Music**)을 엽니다
2. **설정 → Morphe → 기타 → Spoof video streams**를 **Disabled**로 설정합니다
3. **설정 → Morphe → 기타 → PoToken provider**를 **On**으로 켭니다
4. 안내가 나오면 앱을 다시 시작합니다
5. 영상을 재생해 1:00 이후에도 이어지는지 확인합니다

## 그래도 안 되나요?

1. [앱 페이지](/Apps/)에서 **MicroG**, 그다음 YouTube / YouTube Music을 재설치하세요
2. 해결 1에서 다른 재생 모드를 다시 시도하세요
3. PotHelper를 새로 설치한 뒤 해결 2를 다시 시도하세요
4. **설정 → Morphe → 정보**에서 최신 빌드인지 확인하세요

### 고급

Morphe Manager로 직접 앱을 만드는 경우:

1. Manager 왼쪽 아래 스위치로 Morphe 패치 소스의 **pre-release**를 켭니다
2. 최신 패치로 YouTube / YouTube Music을 다시 패치합니다

업스트림 논의: [morphe-patches#327](https://github.com/MorpheApp/morphe-patches/issues/327).
