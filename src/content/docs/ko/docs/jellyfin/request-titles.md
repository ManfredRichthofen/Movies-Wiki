**요청 사이트:** [requests.jfapp.xyz](https://requests.jfapp.xyz/)

영화나 프로그램을 찾을 수 없나요? 요청하세요. 검색하고 **요청**을 누른 뒤 **이용 가능**이 되면 라이브러리의 다른 작품처럼 시청하면 됩니다.

:::info[요약]
검색 → **요청** → **이용 가능** 대기 → Jellyfin에서 재생.
:::

(요청 사이트는 Seerr로 동작하며 Jellyfin과 **같은 로그인**을 사용합니다.)

## 시작하기 전에

- [Jellyfin 계정](/ko/docs/jellyfin/set-up-account/)이 필요합니다. 요청 사이트에도 **같은 사용자 이름과 비밀번호**를 쓰세요.
- **Jellyfin**(가장 쉬움) 또는 **요청 웹사이트**에서 요청할 수 있습니다.
- 인기 작품은 보통 몇 시간 안에 나옵니다. 새롭거나 희귀한 작품은 더 걸릴 수 있습니다.

## Jellyfin에서 요청 (가장 쉬움)

1. [jfapp.xyz](https://jfapp.xyz)를 열고 로그인합니다.
2. **검색** 바에 원하는 영화나 프로그램을 입력합니다.
3. 아직 라이브러리에 없으면 **요청**이 보여야 합니다.
4. **요청**을 탭하고 확인합니다 (TV면 시즌을 선택).
5. 준비되면 다시 검색하거나 홈 화면을 확인하세요.

:::tip
이미 라이브러리에 있으면 **요청** 대신 **재생**이 보입니다.
:::

## 웹사이트에서 요청

### 1. 요청 사이트 열기

브라우저에서 **[requests.jfapp.xyz](https://requests.jfapp.xyz/)** 로 이동합니다.

### 2. 로그인

**Jellyfin 사용자 이름과 비밀번호**를 사용하세요.

로그인이 안 되면 먼저 [초대 링크 설정](/ko/docs/jellyfin/set-up-account/)을 마치세요. 그래도 안 되면 관리자에게 문의하세요.

### 3. 검색하고 요청

1. **Movies** 또는 **Series**를 고른 뒤 검색합니다.
2. 작품을 열고 **Request**를 클릭합니다.
3. TV면 필요한 시즌을 고릅니다.
4. 확인합니다.

### 4. 진행 상태 확인

사이트의 **Requests**를 엽니다:

| 상태 | 의미 |
| --- | --- |
| **Pending** | 시작 대기 |
| **Approved** | 다운로드 중 |
| **Available** | 시청 가능 |

**Available**이 되면 [jfapp.xyz](https://jfapp.xyz)에서 작품을 검색하세요.

## 팁

- 먼저 Jellyfin에서 검색하세요 — 이미 있을 수 있습니다.
- 여러 버전이 있으면 특별한 이유가 없으면 **영어** 버전을 요청하세요.
- 방영 중인 시리즈는 빠진 최신 시즌을 요청하세요.
- 이미 있는 작품을 다시 요청하면 보통 거절됩니다.

## 문제 해결

### Jellyfin에 요청이 안 보여요

- 로그인했는지, 제목을 정확히 검색했는지 확인하세요.
- [요청 사이트](https://requests.jfapp.xyz/)를 대신 사용해 보세요.
- Jellyfin을 새로고침하거나 로그아웃 후 다시 로그인하세요.

### 요청 사이트에 로그인할 수 없어요

- 먼저 [jfapp.xyz](https://jfapp.xyz)에서 로그인이 되는지 확인하세요.
- **현재** Jellyfin 비밀번호를 사용하세요.

### Pending에 멈춰 있어요

- 희귀 작품은 더 걸릴 수 있습니다. 몇 시간 뒤 다시 확인하세요.
- 24시간이 넘으면 커뮤니티 채널에 물어보세요.

### Available인데 Jellyfin에 없어요

- 페이지를 새로고침하거나 모바일에서 당겨서 새로고침하세요.
- 그래도 없으면 로그아웃 후 다시 로그인하세요.
