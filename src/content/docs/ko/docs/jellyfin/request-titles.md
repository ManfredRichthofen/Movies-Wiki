**요청 사이트:** [requests.jfapp.xyz](https://requests.jfapp.xyz/)

Jellyfin 서버는 **Seerr**와 연결되어 있습니다 — 영화와 TV 프로그램을 검색하고, 없는 작품을 요청하면 라이브러리에 자동으로 추가되는 요청 시스템입니다.

:::info[요약]
작품을 검색 → **요청** 탭 → **이용 가능**이 될 때까지 대기 → Jellyfin에서 시청.
:::

## 시작하기 전에

- [Jellyfin 계정](/ko/docs/jellyfin/set-up-account/)이 필요합니다. Seerr는 **같은 사용자 이름과 비밀번호**를 사용합니다.
- **Jellyfin**(검색 중) 또는 **Seerr 웹사이트**에서 요청할 수 있습니다 — 둘 다 같은 곳으로 갑니다.
- 인기 작품은 보통 몇 시간 안에 나타납니다. 새롭거나 희귀한 작품은 더 걸릴 수 있습니다.

## Jellyfin에서 요청 (가장 쉬움)

Seerr가 서버에 연결되어 있어 둘러보는 중에 요청할 수 있습니다:

1. [jfapp.xyz](https://jfapp.xyz)를 열고 로그인합니다.
2. 상단 **검색** 바에 원하는 영화나 프로그램을 입력합니다.
3. **아직 라이브러리에 없으면** 작품에 **요청** 옵션이 보여야 합니다.
4. **요청**을 탭하고 확인합니다 (TV 프로그램이면 시즌을 선택).
5. 다운로드가 끝나면 Jellyfin 라이브러리에 나타납니다 — 다시 검색하거나 홈 화면을 확인하세요.

:::tip
이미 라이브러리에 있나요? Jellyfin은 **요청** 대신 **재생**을 표시합니다. 두 번 요청할 필요 없습니다.
:::

## Seerr 웹사이트에서 요청

전용 요청 사이트도 사용할 수 있습니다:

### 1. Seerr 열기

웹 브라우저에서 **[requests.jfapp.xyz](https://requests.jfapp.xyz/)**로 이동합니다.

### 2. 로그인

**Jellyfin 사용자 이름과 비밀번호**를 입력한 뒤 **로그인**을 클릭합니다.

첫 방문에서 로그인이 실패하면 [초대 링크 설정을 먼저 완료](/ko/docs/jellyfin/set-up-account/)했는지 확인하세요. 그래도 안 되면 관리자에게 문의하세요.

### 3. 작품 검색

상단 메뉴에서 **영화** 또는 **시리즈**를 선택한 뒤, 스트리밍 서비스를 둘러보듯 원하는 작품을 검색하세요.

### 4. 요청 제출

1. 결과에서 영화나 프로그램을 클릭합니다.
2. **요청**을 클릭합니다.
3. TV 프로그램이면 필요한 시즌을 선택합니다(안내가 나오면).
4. 확인합니다.

### 5. 요청 추적

Seerr의 **요청** 페이지에서 진행 상황을 확인하세요:

| 상태 | 의미 |
| --- | --- |
| **대기 중** | 시작 대기 |
| **승인됨** | 다운로드 진행 중 |
| **이용 가능** | Jellyfin에서 시청 가능 |

요청이 **이용 가능**이 되면 [jfapp.xyz](https://jfapp.xyz)를 열고 작품을 검색하세요 — 있어야 합니다.

## 팁

- 요청하기 전에 Jellyfin에서 먼저 검색하세요 — 이미 있을 수 있습니다.
- 여러 버전이 있으면 다른 언어가 필요하지 않은 한 **영어** 릴리스를 요청하세요.
- 방영 중인 TV 시리즈는 빠진 최신 시즌을 요청하세요 — 이전 시즌은 종종 자동으로 추가됩니다.
- 이미 라이브러리에 있는 작품의 중복 요청은 보통 거절됩니다.

## 문제 해결

### Jellyfin에서 검색했는데 요청이 안 보임

- 로그인했는지, 정확한 제목으로 검색했는지 확인하세요.
- 대신 [요청 사이트](https://requests.jfapp.xyz/)에서 검색하고 결과 페이지에서 요청하세요.
- Jellyfin을 새로고침하거나 로그아웃 후 다시 로그인하세요.

### Seerr에 로그인할 수 없음

- 먼저 [jfapp.xyz](https://jfapp.xyz)에서 Jellyfin 로그인이 되는지 확인하세요.
- **현재** Jellyfin 비밀번호를 사용하세요 — Jellyfin에서 바꾸면 Seerr에도 바로 적용됩니다.

### 요청이 대기 중에 멈춤

- 새롭거나 희귀한 작품은 찾는 데 더 걸릴 수 있습니다.
- 몇 시간 뒤 다시 확인하세요. 24시간이 넘었다면 커뮤니티 채널에 물어보세요.

### 이용 가능인데 Jellyfin에 없음

- 모바일에서는 아래로 당겨 새로고침하거나, 브라우저를 다시 로드하세요.
- 그래도 안 보이면 Jellyfin에서 로그아웃했다가 다시 로그인하세요.
