jfapp는 수천 편의 영화와 프로그램을 갖춘 커뮤니티 Jellyfin 서버를 운영합니다. **Seerr**가 서버에 연결되어 있어, 작품을 검색하고 없으면 요청한 뒤 휴대폰, TV, 브라우저에서 스트리밍할 수 있습니다. 구독은 필요 없습니다.

**서버 주소:** `jfapp.xyz`  
**요청 사이트:** [requests.jfapp.xyz](https://requests.jfapp.xyz/)
