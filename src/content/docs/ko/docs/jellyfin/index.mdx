jfapp는 공유 영화·TV 라이브러리를 운영합니다. 검색하고, 없으면 요청한 뒤 휴대폰·TV·브라우저에서 시청하세요. 구독은 필요 없습니다.

**서버 주소:** `jfapp.xyz`  
**요청 사이트:** [requests.jfapp.xyz](https://requests.jfapp.xyz/)
