검색창 옆 **지구본** 아이콘은 **추가 소스**를 켜고 끕니다. 켜 두면 플레이어가 작품을 재생할 다른 곳을 더 찾을 수 있습니다. 일부 콘텐츠를 찾는 데 도움이 되지만, 데이터를 더 쓰고 연결이 약하면 검색·재생이 느려질 수 있습니다.

:::warning[연결이 느린가요?]
페이지 로딩이 오래 걸리거나, 검색이 멈추거나, 평소보다 버퍼링이 심하면 **추가 소스를 끄세요**. 끄더라도 일반 라이브러리 시청은 그대로입니다.
:::

## 추가 소스 끄기

1. [jfapp.xyz](https://jfapp.xyz)를 열고 로그인합니다.
2. 상단 **검색** 바로 이동합니다.
3. 검색창 왼쪽 **지구본** 아이콘을 눌러 추가 소스를 끕니다.

꺼지면 아이콘이 **사선이 그어진 지구본**으로 바뀝니다:

![추가 소스 꺼짐 — 검색창 옆 슬래시가 있는 지구본 아이콘](/img/remote-stream-disabled.png)

다시 켜려면 같은 아이콘을 한 번 더 누르세요 (예: 더 빠른 Wi‑Fi로 바꾼 뒤).

## 켜 둘 때

연결이 안정적이고 작품을 더 찾아보고 싶을 때는 켜 두세요. 모바일 데이터, 혼잡한 Wi‑Fi, 이미 느린 네트워크에서는 끄는 편이 낫습니다.

## 그래도 문제가 있나요?

- 버퍼링·로그인·연결은 [문제 해결](/ko/docs/jellyfin/troubleshooting/)부터 보세요.
- 재생 중 톱니바퀴에서 화질을 낮추세요.
- 기기별 해결은 [모든 기기에서 시청](/ko/docs/jellyfin/watch-anywhere/)을 참고하세요.
- 라이브러리에 없는 작품이면 추가 소스에 의존하기보다 [요청](/ko/docs/jellyfin/request-titles/)하세요.
