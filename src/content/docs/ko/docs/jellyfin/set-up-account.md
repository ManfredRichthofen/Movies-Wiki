jfapp는 커뮤니티를 위한 비공개 Jellyfin 서버를 운영합니다. 스트리밍하거나 새 작품을 요청하려면 계정이 필요합니다.

## 접근 권한 받기

공개 가입 페이지는 없습니다. 계정이 준비되면 관리자가 **초대 링크**를 보내 드립니다.

1. 받은 **초대 링크**를 엽니다.
2. 화면 안내에 따라 **사용자 이름**을 정하고(요청 시) **비밀번호**를 설정합니다.
3. 설정이 끝나면 jfapp 서버에 연결됩니다 — [jfapp.xyz](https://jfapp.xyz)에서 로그인하세요.

:::info[계정이 필요하신가요?]
jfapp 관리자에게 접근을 요청하세요. 계정이 생성되면 설정을 마칠 수 있는 초대 링크를 받게 됩니다.
:::

:::tip
Jellyfin 로그인은 [Seerr 요청](/ko/docs/jellyfin/request-titles/)에도 동일하게 사용됩니다. [requests.jfapp.xyz](https://requests.jfapp.xyz/)에서도 같은 사용자 이름과 비밀번호를 사용하세요.
:::

## 첫 로그인

초대 링크 설정을 마친 후:

1. 브라우저에서 [jfapp.xyz](https://jfapp.xyz)를 열거나, Jellyfin 클라이언트를 실행한 뒤 서버 **`jfapp.xyz`**를 추가합니다.
2. 설정 시 정한 **사용자 이름과 비밀번호**를 입력합니다.
3. 선택 사항 — 프로필에서 언제든 비밀번호를 변경할 수 있습니다:
   - (오른쪽 위) **프로필 아이콘**을 클릭합니다.
   - **프로필** → **비밀번호**를 엽니다.

:::warning[초대 링크를 아직 사용하지 않으셨나요?]
로그인에 실패했고 초대 링크를 연 적이 없다면, 받은 링크로 돌아가 설정을 먼저 완료하세요. 초대가 끝나기 전에는 수동 로그인이 작동하지 않습니다.
:::

## 다른 기기에서 로그인

서버 주소는 항상 **`jfapp.xyz`**입니다 (대부분의 앱에서는 `https://` 접두사를 넣지 않습니다).

| 플랫폼 | 입력 내용 |
| --- | --- |
| 웹 브라우저 | [jfapp.xyz](https://jfapp.xyz) |
| Android / iOS | 서버: `jfapp.xyz`, 그다음 사용자 이름과 비밀번호 |
| Android TV / Fire TV | **서버 추가** → `jfapp.xyz` |
| 데스크톱 앱 | 서버 URL: `https://jfapp.xyz` |

iPhone 안내는 [iPhone에서 시청](/ko/docs/jellyfin/watch-on-iphone/)을, 모든 플랫폼은 [모든 기기에서 시청](/ko/docs/jellyfin/watch-anywhere/)을 참고하세요.

## 자주 발생하는 문제

### 초대 링크가 만료되었거나 이미 사용됨

- 관리자에게 새 초대 링크를 요청하세요.

### "잘못된 사용자 이름 또는 비밀번호"

- Caps Lock과 철자를 다시 확인하세요.
- 초대 링크 설정을 완료했는지, 그때 설정한 비밀번호를 사용하는지 확인하세요.
- 설정을 방금 마쳤다면 잠시 기다린 뒤 다시 시도하세요.
- 계정이 잠겼다면 관리자에게 비밀번호 재설정을 요청하세요.

### "서버에 연결할 수 없음"

- 서버 주소가 정확히 `jfapp.xyz`인지 확인하세요.
- 장애 여부는 [status.jfapp.xyz](https://status.jfapp.xyz)에서 확인하세요.
- 모바일 데이터에서는 Wi‑Fi로(또는 그 반대로) 바꿔 보세요. 통신사 필터링일 수 있습니다.

### 웹에서는 되는데 앱에서는 안 됨

- 저장된 서버를 삭제한 뒤 `jfapp.xyz`로 다시 추가하세요.
- 스토어 또는 [jellyfin.org/downloads](https://jellyfin.org/downloads)에서 Jellyfin 앱을 최신 버전으로 업데이트하세요.
