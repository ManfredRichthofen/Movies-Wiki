스트리밍이 느리거나, 검색이 멈추거나, 로그인이 안 될 때 이 페이지를 사용하세요. 위에서부터 순서대로 시도하세요 — 대부분 앞 두 섹션에서 해결됩니다.

:::tip[빠른 확인]
- 서버 주소는 항상 **`jfapp.xyz`** (대부분 앱: `https://` 없음)
- 아무 것도 안 열리면 [status.jfapp.xyz](https://status.jfapp.xyz)를 확인하세요
- 모바일 데이터가 안 되면 Wi‑Fi를 시도하세요 (또는 그 반대)
:::

## 버퍼링 또는 느린 재생

1. **화질을 낮추세요** — 재생 중 톱니바퀴 아이콘에서 더 낮은 해상도를 고르세요.
2. **추가 소스를 끄세요** — 검색창 옆 지구본이 약한 연결에서 느려지게 만들 수 있습니다. 다음 섹션을 보세요.
3. **Wi‑Fi에 더 가까이** 가거나, 가능하면 유선을 쓰세요.
4. 휴대폰·TV 앱에서는 잠시 일시정지했다가 다시 재생해 보세요.

그래도 버퍼링되면 [모든 기기에서 시청](/ko/docs/jellyfin/watch-anywhere/)의 기기별 팁을 참고하세요.

## 추가 소스 (지구본 아이콘)

검색창 옆 **지구본**은 추가 재생 소스를 켜고 끕니다. 켜 두면 작품을 재생할 다른 곳을 더 찾을 수 있지만, 데이터를 더 쓰고 **검색·재생이 느려질 수** 있습니다.

**페이지가 느리거나, 검색이 멈추거나, 버퍼링이 심하면 끄세요:**

1. [jfapp.xyz](https://jfapp.xyz)를 열고 로그인합니다.
2. **검색** 바로 이동합니다.
3. 검색창 왼쪽 **지구본**을 눌러 **사선이 그어진 지구본**이 될 때까지 끕니다.

![추가 소스 꺼짐 — 검색창 옆 슬래시가 있는 지구본](/img/remote-stream-disabled.png)

추가 소스를 꺼도 일반 라이브러리는 그대로 시청할 수 있습니다. 자세한 안내: [추가 소스 (지구본 아이콘)](/ko/docs/jellyfin/remote-stream/).

## 연결 또는 로그인이 안 돼요

### “서버에 연결할 수 없음” / 서버를 찾을 수 없음

- `jfapp.xyz`만 정확히 입력하세요 (대부분 모바일/TV 앱: `https://` 없음, 데스크톱은 `https://jfapp.xyz`일 수 있음).
- VPN을 잠시 끄고 다시 시도하세요.
- [status.jfapp.xyz](https://status.jfapp.xyz)를 확인하세요.
- 앱에서 저장된 서버를 지운 뒤 `jfapp.xyz`를 다시 추가하세요.

### “잘못된 사용자 이름 또는 비밀번호”

- Caps Lock과 철자를 확인하세요.
- 먼저 [초대 링크 설정](/ko/docs/jellyfin/set-up-account/)을 마쳤는지 확인하세요.
- 설정 직후라면 잠시 기다렸다가 다시 시도하세요.
- 잠겼다면 관리자에게 비밀번호 재설정을 요청하세요.

### 브라우저에서는 되는데 앱에서는 안 돼요

- 스토어나 [다운로드](/Downloads/) 페이지에서 앱을 업데이트하세요.
- 서버 항목을 지우고 `jfapp.xyz`를 다시 추가하세요.
- 같은 계정으로 [jfapp.xyz](https://jfapp.xyz) 로그인이 되는지 확인하세요.

## 화면 또는 소리 문제

| 증상 | 시도할 방법 |
| --- | --- |
| 영상만 나오고 소리 없음 | 앱 설정에서 **Direct play**를 끄거나 화질을 낮추세요 |
| 초록·보라색으로 깨짐 (데스크톱) | 클라이언트 설정 → 비디오 → **하드웨어 디코딩**을 **사용 안 함** |
| 소리와 영상이 어긋남 | 하드웨어 디코딩을 끄고, 앱·그래픽 드라이버를 업데이트하세요 |
| TV에서 4K가 끊김 | 화질을 1080p로 낮추세요 |

기기별 자세한 내용: [모든 기기에서 시청](/ko/docs/jellyfin/watch-anywhere/).

## 그래도 안 되나요?

- [계정 설정](/ko/docs/jellyfin/set-up-account/) — 초대와 첫 로그인
- [영화나 프로그램 요청](/ko/docs/jellyfin/request-titles/) — 라이브러리에 없는 작품
- [다운로드](/Downloads/) — 앱 재설치 또는 다른 클라이언트
- YouTube 버퍼링인가요? [YouTube 재생 문제 해결](/ko/docs/youtube-apps/playback-issues/)을 참고하세요
